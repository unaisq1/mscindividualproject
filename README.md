# mscindividualproject

MSc Cybersecurity Individual Project by Unais Qureshi

All files and models are in "Model Deliverable" directory, where there are JavaImplementation and SafetyAndSecurityInterplay directories respectively.

**Running the source code**
All code is found in the "JavaImplementation" directory

The main() function can be found in the CompositionalVerification.java class, which is
located under the ”src/com/safetyandsecurity/verification” directory. This will generate
the reports of the set variants that contain the set combination of Sensors, Authentication
and Voting Systems, and Fusion Processors that aim demonstrate the defined safety and
security properties. These variants are located in the ”AVComponentFactory”, where
any further variants can be defined and built through objects across the three layers.

**Accessing Eclipse Papyrus Model Diagrams**
All model files are found in the SafetyAndSecurityInterplay directory

To access the model diagrams, open the BaseModelProject project directory in Papyrus
through File / Open Projects from File System / Directory... / SafetyAndSecurityIn-
terplay / BaseModelProject. Once the project is opened, expand the SafetyAndSecuri-
tyInterplayProject and BaseModelProject fields in the Project, or Package, Explorer to
find the BaseModelProject.di file. Finally, double-click this file to load the models and
layers in the Model Explore
